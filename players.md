# Player's Guide

{: .highlight }
This guide provides comprehensive information for players participating in the MAP Tournament. As a player, you are responsible for maintaining active participation, following tournament rules, and coordinating with your team captain. All tournament matches take place between **Friday 23:59 UTC** and **Monday 23:59 UTC** on their designated weekends. For a complete overview of the tournament, see the [Tournament Overview]({{ site.baseurl }}/tournament-info/core-info/overview/).

## Tournament Format

### Basic Structure
{: .important }
For complete format details, see the [Tournament Format]({{ site.baseurl }}/tournament-info/tournament-structure/format/) page.

- **4v4** international tournament
- Double elimination bracket
- All matches between **Friday 23:59 UTC** and **Monday 23:59 UTC**
- Teams need **two losses** to be eliminated
- Teams in losers' bracket must play **two matches per week** after Round of 16

## Tournament Special Features

### Warmup Gimmick
{: .note }
For complete gimmick details, see the [Gimmicks]({{ site.baseurl }}/tournament-info/tournament-structure/gimmicks/) page.

#### How It Works
The warmup gimmick is a unique feature designed to recognize and reward outstanding maps. During the warmup phase, teams can showcase exceptional maps for a chance to earn a free point.

#### Requirements
- Map must **not** have been seen by mapping board
- Must thoroughly impress mapping board member
- **Exactly 4 players** must participate
- Both teams must agree to participate

#### Participation Process
1. **During Scheduling**
   - Indicate participation in #scheduling
   - Submit warmup map link
   - Wait for mapping board confirmation

2. **Before Match**
   - Have exactly 4 players ready
   - Follow referee instructions
   - Complete warmup as directed

3. **After Warmup**
   - Referee will announce if point awarded
   - Winning maps posted in #warmup-winners
   - Mapping board provides explanation

### Mapper's Choice Bounty System
{: .important }
For complete bounty information, see the [Prizes]({{ site.baseurl }}/tournament-info/tournament-structure/prizes/#mappers-favourite-bounty-system) page.

#### Overview
- Special map selected each round by mapping board
- Two winners per round receive 1 month supporter
- Available in all tournament stages
- Total prize pool: **14 months** supporter

#### How to Participate
1. **Map Selection**
   - Mapper's Favourite announced in mappool showcase
   - Required score threshold specified
   - Teams must meet/exceed threshold to qualify

2. **Attempt Rules**
   - Attempts during official matches only
   - Can attempt after match winner decided (same lobby)
   - One attempt per team per bounty map
   - Maximum 4 players per attempt
   - All participating players attempt simultaneously
   - For multiple match opportunities, only first attempt counts

3. **Prize Distribution**
   - Raffles during next round's mappool showcase
   - Two winners randomly selected from qualifying attempts
   - Players can only win one bounty per round
   - Does not affect tournament placement prizes

#### Prize Schedule

| Round | Prize |
|-------|-------|
| Round of 32 | **2** winners × **1** month supporter |
| Round of 16 | **2** winners × **1** month supporter |
| Quarter Finals | **2** winners × **1** month supporter |
| Semi Finals | **2** winners × **1** month supporter |
| Finals | **2** winners × **1** month supporter |
| Grand Finals | **2** winners × **1** month supporter |

## Technical Support

### Score Verification
{: .important }
For complete troubleshooting guides, see the [FAQ]({{ site.baseurl }}/tournament-info/additional-info/faq/#troubleshooting) page.

Acceptable proof of score includes:

1. **Official Stream Footage**
   - Last visible score will be used

2. **Player POV Recording**
   - Must show entire play including results screen
   - E.g., Twitch stream VOD

3. **Screenshots**
   - Must use osu!'s screenshot function (Shift + F12)
   - Must be hosted on osu.ppy.sh

4. **Phone Recording**
   - Must show the play/score
   - Must show current date/time

### Common Issues
{: .note }
For detailed troubleshooting steps, see our [Support Guide]({{ site.baseurl }}/support/#technical-support).

#### Map Loading Problems
1. Exit multiplayer lobby
2. Delete problematic map
3. Close osu!
4. Download clean version without video
5. Restart osu!

#### Missing Audio (DMCA)
1. Exit multiplayer lobby
2. Delete affected map
3. Close osu!
4. Download from beatconnect.io
5. Restart osu!

#### Connection Issues
1. Verify Bancho connection
2. Try alternative invite methods
3. Restart osu! client
4. Contact referee if problems persist

## FAQ

{: .note }
For a complete list of frequently asked questions, see our [FAQ]({{ site.baseurl }}/tournament-info/additional-info/faq/) page.

### Common Questions

**Q: When are matches played?**
A: Between Friday 23:59 UTC and Monday 23:59 UTC on designated weekends. See [Important Dates]({{ site.baseurl }}/tournament-info/core-info/dates/) for the complete schedule.

**Q: What if I can't make a match time?**
A: Contact your team captain to arrange a substitute or try to reschedule. See [Match Format]({{ site.baseurl }}/tournament-info/match-info/match-format/#rescheduling-process) for details.

**Q: How do I verify my score if disconnected?**
A: Follow the [Score Verification](#score-verification) guidelines above and see [Technical Support]({{ site.baseurl }}/support/#technical-support) for more details.

**Q: What happens if I get restricted?**
A: Notify tournament staff immediately. Your team's status will be evaluated case-by-case according to our [Rules]({{ site.baseurl }}/tournament-info/core-info/rules/#restrictions).
